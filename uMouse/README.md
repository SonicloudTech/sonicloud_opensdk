# 声云智能鼠标 SDK 已迁移至独立仓库 · The Smart Mouse SDK has moved

为便于独立维护与版本发布，声云智能鼠标 SDK（uMouse SDK）已从本仓库拆分至独立仓库，
请前往新仓库获取最新版本与文档：

- **GitHub**：https://github.com/SonicloudTech/mouse-sdk
- **Gitee**：https://gitee.com/SonicloudTech/mouse-sdk

新仓库内容包括：

- Windows x64 / macOS（Apple Silicon）平台二进制交付包（当前版本 0.4.20）；
- **中英双语**接入文档（v2.2：API 参考、事件 JSON 协议、C / C++ / C# / Python / Electron 集成）；
- 头文件与 C 示例源码。
