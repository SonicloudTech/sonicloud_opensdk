# 自动化测试报告与分享

按用户选择，同一个 UTF-8 txt 持续追加全部测试结果，保存在应用文档目录。
每轮测试以两个换行、手机本地开始时间和设备信息开头。
单文件传输记录文件名、大小、重复次数，每次结果、耗时、平均/最高/最低速度。
全部文件传输记录各文件结果，并汇总文件总大小、实际接收大小、耗时、平均速度。
杰理 OTA 记录每轮成功/失败、失败原因和包含连接/校验的总耗时，中断明确标记。

测试页顶行左侧展示设备型号和名称，右侧分享累计报告；OTA 卡片标题改为“杰理OTA自动化测试”，移除卡片内设备信息。
音频和 txt 使用 Android ACTION_SEND / iOS UIActivityViewController 系统分享面板，替换原有保存位置选择器。
分享快照放在缓存中，避免原文件追加或覆盖影响微信/QQ 延迟读取；旧缓存定期清理。
报告磁盘写入串行化并及时 flush，写入失败保留待写内容并在测试页展示错误，不改变测试的成功/失败统计。

实现沿用现有原生通道，无新增分享 SDK；相较引入插件，变更更集中。扩展名过滤与音频封装保持原有实现。
保留已有用户改动，不创建新工作树，不提交现有混合工作区，不作无关格式修改。
