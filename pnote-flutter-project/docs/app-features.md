# PNote Project 功能清单（供 UI 设计参考）

> 录音笔（智能笔）配套 Flutter 工程 · 双端（Android/iOS）· 中英双语可切换
> 设计基调：欧美商用风 · 主色靛蓝 `#635BFF` · 白卡片 + 细边框 + 12px 圆角 · 克制配色（语义色只做小面积点缀）

---

## 全局框架

- **底部 Tab 导航**（2 个）：「设备」/「录音文件」
- **AppBar**：左标题 "PNote Project"；右侧语言菜单（跟随系统 / English / 中文）
- **AppBar 右上角设备摘要**（仅连接后）：`绿点(在线状态) + 设备名 + 竖版电量图形(按电量百分比填充) + 小箭头`，单行排布，点击进入「设备信息页」
- 通用规范：状态一律**文字+颜色双编码**；计时/时长用等宽数字；触控目标 ≥44pt

## 1. 设备页（首页 Tab1）

### 1a. 未连接 · 扫描视图
| 元素 | 说明 |
|---|---|
| 引导区 | 圆形图标 + 「查找你的录音笔」标题 + 副标题 |
| 异常提示卡 | 蓝牙未开启（黄色警示）/ 权限被拒（红色警示），带「重试 / 去系统设置」按钮 |
| 主按钮 | 「扫描设备」/「停止扫描」（扫描中变停止 + 加载态） |
| 重连入口 | 「重连 上次设备名」（有历史时显示） |
| 附近设备列表 | 每行：麦克风图标 + 设备名 + MAC + 信号强度 dBm + 箭头，点击即连接 |

### 1b. 已连接 · 仪表盘
| 元素 | 说明 |
|---|---|
| 录音卡 | 状态行（就绪 / 录音中·红 / 已暂停·琥珀，图标+文字+颜色）+ 计时器；主按钮「录音」⇄「停止并保存」，录制中露出副按钮「暂停 / 继续」 |
| 近期录音 | **紧贴录音卡下方**（本地数据，未连接也显示）；最多 5 条；每行：音频波形图标 + 名称 + `时长 · 日期` + 箭头；点击进「音频详情页」 |

## 2. 录音全屏页（自动弹出）

- **触发**：录音开始即自动全屏弹出（App 点按钮 或 笔身物理按键开录，任意 Tab 下都会弹）
- **锁定**：录音期间不可退出（系统返回键 / 侧滑手势均被拦截）
- **自动返回**：停止录音（App 按钮 / 物理键 / 意外断连）自动回到首页

| 元素 | 说明 |
|---|---|
| 状态 | 录音中（红·圆点图标）/ 已暂停（琥珀·暂停图标），居中 |
| 计时器 | 超大号 `mm:ss` / `h:mm:ss`，等宽数字 |
| 实时转写卡 | 占满中部：ASR 连接徽标（已连接·绿 / 连接中·琥珀 / 已断开·红）+「实时转写」标题；正文区：定稿正文（黑）+ 临时句「正在说」（主色斜体），自动滚到最新 |
| 转写未开启 | 显示「本次录音未开启实时转写」提示（音频仍正常保存） |
| 底部操作 | 左「暂停 / 继续」（描边按钮）+ 右「停止并保存」（主色实心按钮） |

## 3. 设备信息页（AppBar 摘要点击进入）

| 元素 | 说明 |
|---|---|
| AppBar | 标题「设备信息」+ 刷新按钮 |
| 设备头卡 | 大图标 + 设备名 + MAC 地址 + 「已连接」徽标（绿） |
| 电量行 | 电池图标 + 百分比 + 进度条（≤20% 红 / ≤50% 琥珀 / 其余绿；充电换充电图标） |
| 存储行 | 存储图标 + `已用 / 总量` + 进度条（主色） |
| 信息格 | 固件版本 / 对时状态 两个小格 |
| 断开连接 | 底部红色描边按钮（破坏性操作，与信息区拉开距离）；断连后本页自动返回首页 |

## 4. 录音文件页（Tab2 · 设备上的文件）

- **每次进入自动刷新**列表（下拉刷新也可）
- 列表头：`录音文件 · 数量` + 刷新 + 「全部删除」（红色文字，二次确认）
- 未连接：空态插画位 + 「未连接设备」+ 引导文案

| 文件状态 | 展示与交互 |
|---|---|
| 未下载 | 行尾下载图标；副标题 `点击下载 · 时长 · 大小`；点行或图标开始下载 |
| 下载中 | 进度条 + `下载中… xx%`；行尾**暂停按钮**（⏸） |
| 已暂停 | 进度条冻结 + `已暂停 · 已收大小`；行尾**继续按钮**（▶）/ 点行也可继续；**断点续传**，从暂停处接着下 |
| 已下载 | 图标变主色波形；播放按钮（▶/⏸ 切换） |
| 删除 | 行尾删除图标 → 确认弹窗（红色确认键）；支持单个 / 全部删除 |

- **迷你播放条**（页面底部，播放中出现）：播放/暂停 + 文件名 + `当前/总时长` + 进度条可拖动 + 关闭

## 5. 音频详情页（本地录音 · 近期录音点击进入）

从上到下：

| 区块 | 说明 |
|---|---|
| 音频信息卡 | 波形图标 + 名称；三个信息格：时长 / 大小 / 保存时间 |
| 播放卡 | 进入**不自动播放**：播放大按钮 + `当前/总时长` + 可拖动进度条；首次进入有「准备播放…」转换态；失败显示错误文案 |
| 转写内容卡 | 录音过程中实时转写的**定稿文本**，一行一句（仅 App 自录且开了转写才有此卡；设备下载文件无） |
| AI 生成按钮 | **底部居中**，✨ 图标主色按钮；点击提示「此功能后续开放，敬请期待」（占位入口） |

## 6. 数据与同步逻辑（设计需知的状态来源）

- **本地录音**：录音开始即把实时音频流存到手机（`recordings/app/`），停止/断连自动入库；断连保留半段可播；空录音不保留
- **转写文本**：停录时随音频存同名 txt，详情页展示
- **近期录音列表**：自录 + 设备下载文件**统一汇总**（下载完成即进列表）；App 重启后列表保留；删除文件同步移出
- **双来源播放**：自录（app 子目录）与下载（根目录）路径隔离，均 opus → wav 转换后播放
- **物理按键镜像**：笔身上的开始/停止/暂停/继续按键全部同步到 App（含自动弹出录音全屏页）；设备端直接操作的暂停/停止也会反映到 UI
- 事件日志引擎存在（动态页当前对客户隐藏）

## 7. 页面跳转关系

```
首页(Tab1)                        录音文件(Tab2)
 ├─ 未连接：扫描视图                ├─ 未连接：空态
 └─ 已连接：录音卡 + 近期录音        └─ 文件列表 ─ 迷你播放条
        │ 点击近期录音                     │ 点击行下载（可暂停/续传）
        ▼                                 ▼
     音频详情页（信息/播放/转写/AI占位）
        
AppBar 设备摘要(点击) ──► 设备信息页（刷新/断连）
录音开始(任意来源) ──► 录音全屏页（锁定，停止自动返回）
```
